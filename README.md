# AfyaCheck (Vercel + GitHub)

PWA ya PHP + MySQL inayochambua dalili za kiafya kwa Kiswahili (Gemini AI).

```
api/index.php   router mmoja wa kurasa zote za PHP (Vercel PHP runtime)
app/            kurasa za PHP, includes/, api/chat.php
public/         faili tuli: assets/, sw.js, manifest.json, offline.html
database/       install.sql (schema kamili, ikiwemo jedwali la sessions)
vercel.json     usanidi wa Vercel (runtime, rewrites, headers)
```

Maelekezo kamili ya kuweka mtandaoni: **DEPLOY.md**
